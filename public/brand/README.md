# TurboWatch identity assets

Original TurboWatch lightning geometry is reused from the existing app icon. The wordmark keeps the established turbo/watch weight contrast and coral period.

- `turbowatch-icon.svg` — square app mark, 64 × 64 viewBox.
- `turbowatch-wordmark-light.svg` — pine wordmark for light backgrounds.
- `turbowatch-wordmark-dark.svg` — paper wordmark for dark backgrounds.
- `social-preview.png` — 1200 × 630 preview exported from the original launch kit and used by the app’s Open Graph/Twitter metadata; pictured sample content is labeled.

The SVG wordmarks use outlined glyphs and do not require an installed font. Glyphs are derived from the existing bundled Manrope font (SIL Open Font License; see `../media/MANROPE-OFL.txt`). Do not distort the marks or alter the lightning geometry. Leave at least half the mark height as clear space where practical.
